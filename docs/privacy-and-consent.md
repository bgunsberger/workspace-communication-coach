# Privacy And Consent

This tool is intended for personal reflection on your own authored workplace communication.

Recommended boundaries:

- Analyse only the authenticated user's own sent/authored content.
- Avoid storing raw data longer than necessary.
- Keep generated reports private unless all sensitive content is removed.
- Do not use this for employee monitoring.
- Do not analyse colleagues' communication without consent.
- Remove company names, person names, document IDs, and raw snippets before publishing examples.

The public repository uses synthetic examples only.

## Sensitive Files

Never commit:

- OAuth credentials
- OAuth refresh tokens
- raw daily exports
- real report JSON
- Google Doc IDs
- private meeting transcript content
